## 工程问题记录：git push 走 HTTPS 失败
- 现象：`github.com:443` 端口可连通（nc 通），但 git over HTTPS 报 `HTTP2 framing layer` / `Empty reply from server` / 连接超时 75s 后失败；同时 `api.github.com` 正常 200
- 绕行方案（有效）：`git push ssh://git@ssh.github.com:443/lfxsjw/dealnest.git HEAD:main`，SSH 走 443 端口认证成功并推送；remote 配置未改动，不影响另一个窗口
- 结论：以后 push 失败先试这条 SSH-443 命令，别反复重试 HTTPS
